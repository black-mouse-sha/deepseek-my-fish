完整带版本号的清单见仓库根的 [`plugins.json`](../plugins.json)。

## 三、注意

1. **插件自带的数据也在 `%USERPROFILE%\.dsh` 下**
   例如 `dsh-whale-widget` 的图片在它自己的 `assets\`，宠物状态在 `.dsh\pet.json`。
   换机时插件要重装，但**状态文件可以单独搬**（见仓库 README 的「搬家」部分）。

2. **插件版本不匹配可能起不来**
   DSH 大版本更新后，旧插件常常报错。装之前瞄一眼插件的 `package.json` 里的
   `peerDependencies` 或 README 的兼容说明。

3. **装太多会拖慢启动**
   每个插件都会往渲染进程塞资源。体积前 3 名（43 + 15 + 8 MB）加起来就 66 MB，
   只在需要时启用。

4. **别装来源不明的插件**
   插件跑在宿主进程里，权限等于你的账号权限。
