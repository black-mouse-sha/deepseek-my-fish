# 快速开始

> 目标：5 分钟内让助手变成"你的鱼"。

---

## 0. 前置

| 需要 | 说明 |
|---|---|
| Windows 10/11 | 目前只在 Windows 上验证过 |
| [DeepSeek Harness](https://github.com/deepseek-ai) | 官网下载安装，**先启动一次**让它下载运行时（约 264 MB） |
| PowerShell | 系统自带 |

---

## 1. 拿到仓库

```powershell
git clone https://github.com/<你的账号>/deepseek-my-fish.git
cd deepseek-my-fish
```

没有 git 也行：网页右上角 `Code` → `Download ZIP` → 解压。

---

## 2. 跑安装脚本

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
```

脚本会：

```
[1/5] 人格      -> %USERPROFILE%\.dsh\prompt-inject.md + AGENTS.md + rules\
[2/5] 预设      -> %USERPROFILE%\.dsh\.agent-presets\
[3/5] 红队库    -> %USERPROFILE%\.dsh\redteam\skills + pocs + config.json
[4/5] 工具      -> %USERPROFILE%\.dsh\dsh-purge\tools\
[5/5] 挂件资源  -> %USERPROFILE%\.dsh\whale-roles\
```

**可重复运行**，不会重复叠加。已有同名文件时会先问你。

---

## 3. 重启并验证

**完全退出** DSH（托盘图标也要退），重新打开，新开一个会话。

然后逐项对：

| 检查 | 期望 |
|---|---|
| 说「你好」 | 不叫"AI 助手"，有自己的名字和语气 |
| 问「你是谁」 | 说出人格设定里的身份 |
| 看 `.dsh\AGENTS.md` | 文件存在、内容是你写的 |
| 换会话 | 人格仍然生效 |

---

## 4. 想反悔

```powershell
# 方案 A：只删人格
Remove-Item "$env:USERPROFILE\.dsh\prompt-inject.md"
Remove-Item "$env:USERPROFILE\.dsh\AGENTS.md"

# 方案 B：连规则集一起删
Remove-Item "$env:USERPROFILE\.dsh\rules" -Recurse
```

重启 → 回到出厂语气。
